# tools/audit — أدواتُ قياسِ برنامجِ الهجرةِ السياديّة · بطاقةُ هويّة

## الهدف
أن يكونَ كلُّ رقمٍ في وثائقِ `docs/audit/` **مُعادَ التوليدِ بأمرٍ واحدٍ** لا منقولًا عن
ذاكرةِ وكيل. فهذه الأدواتُ تقيسُ المستودعَ وتكتبُ مُخرَجَها الخامَّ في
`docs/audit/measurements/`، ثمَّ تُقرأُ الأرقامُ من هناك لا من نصٍّ محفوظ.

## النطاق
**القياسُ وحدَه، والامتناعُ عن الإصلاحِ شرطُ صحّةٍ فيه لا نقصٌ:** أداةٌ تقيسُ وتُصلِحُ
تُخفي ما قاسَتْه. فما في هذا المجلَّدِ:

* **جردُ مواضعِ الكتابةِ** ومَن عبرَ منها الحدَّ السياديَّ ومَن لم يعبُرْ — ومنه يُشتَقُّ
  رقمُ الدَّينِ وحدَه.
* **مصفوفاتُ حكمِ البوابةِ** على أفعالٍ مرشَّحةٍ × فاعلين، مقروءةً من المُحرِّكِ
  الدستوريِّ نفسِه لا مُقدَّرةً من نصِّ المعجم.
* **التدقيقُ النهائيُّ** الذي يُطابِقُ الوثيقةَ بالمستودعِ ويُعلِنُ كلَّ لا-تطابق.
* **بوابةُ إعادةِ الجردِ** بينَ موجاتِ القرارِ البشريّ.

**وما ليسَ في نطاقِها — ويُعلَنُ لئلّا يُفترَض:** لا تُخوِّلُ هذه الأدواتُ كتابةً ولا
تمنعُها، ولا تُنتِجُ دليلًا سياديًّا (ذاك `docs/audit/evidence/evidence_registry.jsonl`
بسلسلةِ تجزئتِه)، ولا تحملُ نصَّ قرارٍ ولا حالتَه (ذاك
`docs/audit/SOVEREIGN_DECISION_REGISTER.md` وحدَه — وإن خالفَه مُخرَجُ أداةٍ فالسجلُّ
هو الحاكم).

## المالك
`tools/audit` — ديوانُ التدقيق. ومُخرَجاتُها مملوكةٌ لـ`docs/audit/measurements/`
ولا تُكتَبُ في `docs/audit/evidence/` المملوكِ لـ`tools/governance`.

## الاستعمال
```
python tools/audit/sovereign_write_inventory.py            # الجرد
python tools/audit/sovereign_write_inventory.py --json OUT # مُخرَجٌ خامّ
python tools/audit/treasury_gate_probe.py                  # مصفوفةُ أفعالِ المال
python tools/audit/judicial_gate_probe.py                  # مصفوفةُ القضاءِ والتشريع
python tools/audit/final_audit.py                          # مطابقةُ المستودعِ بالوثيقة
python tools/audit/decision_gate.py --map                  # خريطةُ الموجاتِ المقيسة
python tools/audit/decision_gate.py --measure              # قياسٌ بلا كتابة
python tools/audit/decision_gate.py --record Q-NN          # لقطةٌ لقرارٍ أُغلِق
python tools/audit/decision_gate.py --gate Wn              # فتحُ موجةٍ أو السقوطُ مُعلِنًا
```
