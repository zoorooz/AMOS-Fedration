# backups/

## التعريف
نسخٌ احتياطيةٌ للصفوف المتأثرةِ **قبل** تطبيق ترحيلٍ على قاعدةٍ حقيقية. هي دليلٌ
تاريخيٌّ يُحفَظ كما أُخِذ: لا يُحرَّر ولا تُصحَّح قيمُه لاحقًا، لأنّ قيمتَه في أنّه
يشهد على الحالة وقتَ أخذِه.

## النطاق
`docs/audit/backups/` — ملفّاتُ JSON لنسخِ ما قبل الترحيل، كلُّ ملفٍّ يُعلن في
ترويسته هدفَه والقاعدةَ التي أُخِذ منها والسياسةَ التي أُخِذ بموجبها.

## ما لا يُدَّعى
هذه ليست نسخًا احتياطيةً للنظام ولا خطةَ استرداد: لا تشمل القاعدةَ كاملةً، ولا
جدولةَ نسخٍ دورية، ولا استرجاعًا مُختبَرًا. النسخُ التشغيليةُ الكاملةُ **UNAVAILABLE**.
