# سجلُّ الأدلّة — بطاقةُ هويّة

## الهدف
حفظُ الأدلّةِ التي تُبنى عليها أحكامُ `TRUTH_MATRIX.md`، بحيث يصير كلُّ عمودٍ
في المصفوفة مسنودًا إلى مخرَجِ آلةٍ شُغِّلت فعلًا، لا إلى تقديرٍ لفظيٍّ يُستخرَج
من نصِّ المستودع.

## النطاق
`evidence_registry.jsonl` — سجلٌّ إلحاقيٌّ متسلسلُ التجزئة. كلُّ قيدٍ يحمل:
النوعَ، والإقليمَ، والقدرةَ، والحكمَ (`PASS` · `FAIL` · `INCONCLUSIVE`)،
والمُنتِجَ، ووقتَ الإنتاج، والمخرَجَ المصدرَ وبصمتَه، وبصمةَ القيدِ السابق.

## المالك
`tools/governance` — الأداةُ `evidence_registry.py` تكتب، والأداةُ
`truth_audit.py` تقرأ ولا تكتب.

## لماذا وُجِد هذا السجلّ — العطلُ الذي أنشأه

كان `truth_audit.py` يُصدِر عمودَي `TESTED` و`DEPLOYED` هكذا حرفيًّا:

```python
rep.test_refs = len(re.findall(rf"\b{dom}\b", self.test_corpus))
rep.deployed  = bool(re.search(rf"\b{dom}\b", self.deploy_corpus))
```

أي أنّ الإقليمَ يُشهَد له بالاختبار لأنّ **اسمَه ورد ككلمةٍ** في نصِّ ملفّات
الاختبار، ويُشهَد له بالنشر لأنّ اسمَه ورد في نصِّ Dockerfile أو CI. وكلمةُ
`core` ترد بحكم كونها اسمَ حزمةٍ في كلّ سطرِ استيراد، فلم يكن في وسع إقليمٍ أن
يخسر العمودَ أبدًا: كان العمودُ يقيس شعبيّةَ كلمةٍ لا تغطيةَ اختبار.

وهذا ليس قياسًا ضعيفًا بل **دورٌ مغلق**: المدقّقُ يُنتِج بنفسِه الدليلَ الذي
يحكم به، فلا يمسّ حكمُه الواقعَ في أيّ نقطة. وقد كان الأثرُ مقيسًا: قبل الربط
كانت الأقاليمُ الاثنا عشر كلُّها `TESTED = true`؛ وبعده صار الحكمُ ثلاثةً
تملك دليلًا وتسعةً `ABSENT`. وإقليمُ `interfaces` كان يُشهَد له بالاختبار
بورودَين اثنين لاسمِه.

## القواعدُ التي يحرسها هذا السجلّ

1. **الدليلُ لا يُعلَن يدويًّا.** كلُّ قيدٍ يلزمه `producer` و`source_artifact`
   و`source_digest`، ويُرفَض القيدُ الذي لا يحملها. فلا يستطيع وكيلٌ — بشريٌّ
   أو آليٌّ — أن يكتب `PASS` بيده.
2. **السجلُّ لا يصنع الحقيقة بل ينقلها.** لا يقرّر هذا السجلُّ أنّ قدرةً
   مُثبَتة؛ إنّما يجمع مخرَجاتِ الآلات، و`truth_audit.py` هو من يحكم.
3. **الغيابُ ليس نجاحًا ولا فشلًا.** الحكمُ الغائبُ يُكتَب `ABSENT` صريحًا، ولا
   يُقرأ فراغًا يُفسَّر لصالح المستودع.
4. **لا تعديلَ بعد التثبيت.** التجزئةُ متسلسلةٌ، وأيُّ تحريرٍ لقيدٍ سابقٍ يكسر
   السلسلةَ فتُرفَض القراءةُ منها كلُّها.
5. **النسبةُ إلى الإقليم بالاستيرادِ لا بالنصّ.** يُنسَب الاختبارُ إلى إقليمٍ
   بتحليلِ ما يستورده فعلًا عبر `ast`، لا بورودِ الاسم في تعليقٍ أو نصّ.

## الاستعمال

```bash
# تثبيتُ دليلٍ من تقرير JUnit
python3 tools/governance/evidence_registry.py ingest \
    --format junit --artifact /tmp/reports/root_junit.xml \
    --producer "python -m pytest tests/ --junitxml"

# تثبيتُ دليلِ تغطية
python3 tools/governance/evidence_registry.py ingest \
    --format coverage --artifact /tmp/reports/root_cov.xml

# التحقّقُ من سلامة السلسلة
python3 tools/governance/evidence_registry.py verify

# قراءةُ الخلاصة
python3 tools/governance/evidence_registry.py report
```

## ما لا يُدَّعى

هذا السجلُّ **لا يُثبِت** أنّ الدولةَ عاملة. هو يُثبِت أنّ ما يُقال عن
الاختبارِ والتغطيةِ والنشرِ مسنودٌ إلى مخرَجٍ حقيقيّ. وأنواعُ الأدلّةِ
`RUNTIME_TRACE` و`PERSISTENCE` و`RECOVERY_DRILL` و`SECURITY_CHECK`
و`DEPLOYMENT` معرَّفةٌ في الأداة ولمّا تُملأ بعد — وغيابُها ظاهرٌ في التقرير
`ABSENT` ولا يُخفى.
